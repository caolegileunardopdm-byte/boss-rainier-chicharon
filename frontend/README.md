# 🥓 Boss Rainier Chicharon — Sales & Inventory System

A **web-based sales and inventory system** for **Boss Rainier Chicharon**, a local retail business located in Patubig, Marilao, Bulacan.

The system provides customers with a convenient way to order chicharon and other products online, while giving store management a centralized platform for tracking orders, sales, and inventory in real time.

## ✨ Features

### 🛒 Customer Features

- ✅ User registration and login (JWT authentication)
- ✅ Browse products with categories
- ✅ Search and filter products
- ✅ Add to cart with quantity controls
- ✅ Checkout with pick-up scheduling
- ✅ Multiple payment methods:
  - Cash on Pick-up
  - GCash
  - Maya
  - Bank Transfer
- ✅ Order tracking with status updates
- ✅ Order history

### 🛠️ Admin Features

- ✅ Admin dashboard with statistics
- ✅ Product management (Create, Read, Update, Delete)
- ✅ Category management
- ✅ Order management with status updates
- ✅ Inventory management with low-stock alerts
- ✅ User management (Customers, Staff, Admin)
- ✅ Payment management

### 🔒 Security Features

- ✅ Password hashing with bcrypt
- ✅ JWT token authentication
- ✅ Role-based access control (Customer, Staff, Admin)
- ✅ Protected admin routes
